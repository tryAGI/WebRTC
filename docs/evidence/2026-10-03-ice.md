# UDP ICE milestone evidence

Implementation: `87e7139b2fcfb8a8371d524218f7fb94dc6ec8f3`.

[Validate run 37119261886](https://github.com/tryAGI/WebRTC/actions/runs/37119261886)
completed successfully: protocol/network tests on Linux, Windows and macOS,
whole-library-rooted NativeAOT on Linux x64 with executed authenticated UDP smoke,
and the independent local Pion peer. Local Linux arm64 NativeAOT also compiled
and executed the authenticated ICE connection. No trim warnings were suppressed.

- 14 protocol case groups passed, including a separately generated STUN auth vector,
  writer bounds, malformed inputs and credential/candidate validation.
- 19 network cases passed in the independent-peer container: IPv4/IPv6, both role
  collisions, trickle/reflexive learning, packet loss/retries, candidate fallback,
  wrong credentials, source admission, consent expiry, cancellation, queue/pair limits,
  early-request authentication/identity/expiry and Pion in both roles.
- Pion ICE `v4.4.5`, commit `54a22240c3afddd0b32f5420a62f253f000c225c`; full test-peer
  module hashes and linked-module license notices are committed. Its pinned compiler
  is Go 1.26.8. These are isolated test dependencies, not .NET runtime dependencies.
- A startup race was observed locally before early buffering: a first Pion check
  arrived before remote credentials were applied, leading to an approximately
  400-ms retry wait. The new delayed-signaling case deliberately waits 100 ms after
  observing an early request, then validates it after signaling without waiting for
  that RTO. Local selected-pair timing after applying credentials was below 1 ms in
  the final run. This is a scoped mechanism check, not a production voice benchmark.

No DId, Advantage or Simli provider session was migrated or exercised in this
milestone. DTLS/SRTP, SDP/media/RTCP, SCTP/DCEP, NAT/relay/resolution and physical
Watch acceptance remain required by [the completion matrix](../acceptance.md).
