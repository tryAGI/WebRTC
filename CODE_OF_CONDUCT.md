# Code of conduct

Treat contributors and users with respect. Critique code and ideas constructively;
welcome questions, acknowledge mistakes and avoid personal attacks.

Harassment, discrimination, threats, doxxing, unwanted sexual attention and disclosure
of private information are not acceptable in project spaces or project-related contact.
Do not publish credentials, private communications or recordings without consent.

Maintainer [HavenDV](https://github.com/HavenDV) handles conduct concerns. Contact the
maintainer through an available private channel for sensitive details; do not expose
those details in a public issue. If private contact is unavailable, request a contact
channel without naming affected people or sharing the incident publicly. Security
vulnerabilities use the separate [private security reporting process](SECURITY.md).

Maintainers may edit or remove harmful content, ask participants to change behavior,
or restrict participation. Responses should reflect the conduct, context and impact.
This policy applies to issues, pull requests, discussions and other project spaces.

This is an independently authored project policy.
